## Краткое описание работ

### Лабораторная работа №1 — Простейшие программы

Консольное приложение, вычисляющее значение математической функции по
индивидуальному варианту (вариант №2: `f = π·ln(β⁵)/(sin α + 1)`).
Отрабатываются объявление переменных/констант, использование класса `Math`,
ввод через `Console.ReadLine()` и форматированный вывод результата.

### Лабораторная работа №2 — Управляющие конструкции

Консольное меню из трёх пунктов («Отгадай ответ», «Об авторе», «Выход»).
Игровая логика переносит вычисления из лабы №1: пользователь вводит `a` и
`b`, программа считает результат и предлагает угадать ответ за 3 попытки.
Реализованы контроль ввода через `while` + `TryParse` и обработка ошибок
(деление на 0, корень из отрицательного числа) без использования
`break`/`goto`/`continue`/`return` для выхода из циклов.

### Лабораторная работа №3 — Одномерные массивы и методы

Развитие лабы №2: добавлен пункт меню «Сортировка массива». Массив
заполняется случайными значениями, сортируется двумя разными алгоритмами
(по вариантам), сравнивается время выполнения. Вся логика вынесена из
`Main` в отдельные переиспользуемые методы (ввод, создание/копирование
массива, вывод, сортировка, игра).

### Лабораторная работа №4 — Многомерные массивы

Развитие лабы №3: добавлен пункт меню «Игра». Реализована консольная игра
**«Тетрис»** (вариант №2) на игровом поле 10×10, представленном
двумерным массивом:
- фигуры разных форм падают сверху и управляются пользователем (влево/вправо);
- при заполнении ряда он удаляется, а верхние ряды смещаются вниз, начисляются очки;
- игра завершается при заполнении поля до верхней границы.

Логика разбита на методы: инициализация поля, отрисовка, обработка ввода,
обновление состояния, проверка условий окончания игры.

### Лабораторная работа №5 — Классы и XML-документирование

Та же функциональность (игра-угадайка + Тетрис из лабы №4), но
переработанная в ООП-стиле: логика распределена по отдельным классам
(статический класс игры-угадайки, класс работы с массивами с приватными
полями и свойствами, статический класс валидации ввода, класс с
реализацией Тетриса). Каждый класс — в отдельном файле, публичные члены
задокументированы XML-комментариями.

### Лабораторная работа №6 — Windows-приложение

WPF-приложение поверх классов из лабы №5, с несколькими окнами:
1. **Игра-угадайка** — формула на экране, поле ввода количества попыток,
   таймер и прогресс-бар обратного отсчёта.
2. **Работа с одномерными массивами** — ручной/случайный ввод массива,
   отображение и редактирование через `DataGridView`, сортировка, поиск
   min/max и среднего с подсветкой в таблице.
3. **Игра «Тетрис»** — то же поле, но взаимодействие через клики по
   ячейкам `DataGridView` вместо ввода координат.
4. **Окно «Об авторе»**.

При выходе из приложения запрашивается подтверждение.

## Как запустить лабораторную

1. Открыть `.sln`-файл нужной папки (например, `lab1/Lab1.sln`) в Visual Studio.
2. Собрать проект (Build → Build Solution).
3. Запустить (`Ctrl+F5` — без отладчика, `F5` — с отладчиком).
