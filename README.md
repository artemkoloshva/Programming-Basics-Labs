# Вариант 2. Тетрис
1. Цель. Создать консольное приложение на языке C#, моделирующее игру «Тетрис», в которой игрок управляет падающими блоками на поле размером 10x10, стараясь не допустить, чтобы блоки заполнили игровое пространство до верхней границы.
2. Игровое поле.
Поле представляет собой двумерный массив размером 10x10, где каждый элемент массива — это клетка, которая может быть либо пустой, либо заполненной частью блока.
Поле обновляется с каждым шагом, отображая движение падающего блока и зафиксированные блоки на месте.
3. Фигуры.
Блоки различных форм (например, линии, квадраты, L-образные) падают сверху поля.
Каждая фигура начинает падение с верхней части поля и движется вниз с шагом.
4. Управление блоками.
Игрок управляет падением блоков, перемещая их влево и вправо с помощью клавиш ввода.
Блоки продолжают падение до тех пор, пока не достигнут дна поля или не столкнутся с другим зафиксированным блоком.
5. Фиксация блоков.
Когда блок касается дна игрового поля или другого зафиксированного блока, он прекращает падение и остаётся на месте.
После этого появляется новая фигура, которая начинает падать с верхней части поля.
6. Удаление рядов.
Если какой-либо ряд поля полностью заполняется блоками, этот ряд удаляется, а все ряды выше смещаются вниз на одну строку.
Удаление ряда приносит игроку очки и освобождает пространство для новых блоков.
7. Конец игры.
Игра завершается, если зафиксированные блоки достигают верхней границы поля, и новый блок больше не может появиться на поле.
Цель игрока — максимально долго удерживать игру, не давая блокам достичь верха.
8. Дополнительные функции (обязательно).
Подсчёт очков за каждый удалённый ряд.
Обработка ввода для управления движением и поворотом блоков.
